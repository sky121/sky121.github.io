    How it works

    This page cannot watch anything by itself. A browser on sky121.github.io is not allowed to fetch a retailer's product page — there are no CORS headers on it, so the request dies before it is even sent. So the watching happens somewhere with open internet: a scheduled GitHub Actions job wakes up roughly every quarter of an hour, fetches each configured product URL one at a time with an honest user agent, obeys robots.txt, and reads the result.

    It reads in order of trust: schema.org JSON-LD first, then Open Graph product meta tags, then the text of the actual buy control — “Add to cart” against “Notify me when available”. If none of those speak, it records unknown rather than guessing, and says so loudly. Each card shows which signal it used, so the verdict can always be audited.

    Readings are committed into the repository as JSON — only when something actually changed, or every six hours as a heartbeat — and this page simply reads that file. A real change also opens a GitHub issue, which arrives as an email. No third-party service, no API keys, nothing stored in your browser.

    Each camera declares what it wants to be told about. The Z fc is out of stock everywhere, so its first in-stock reading is the whole point: it is watched for restocks and price drops. The Z f is normally on the shelf, so a restock alert would be noise — it is watched for price drops only. Its stock is still fetched, still recorded and still shown above; it simply never pings. One alert ignores the setting entirely: if a page that used to parse cleanly stops making sense, that is reported for every camera, because a blind watcher is always worth knowing about.
